# Queueing Theory

I study a five-station bike-sharing network with analytical queueing models and Python discrete-event simulations. The notebook covers Kelly's product-form solution, travel times, docking capacities, waiting queues, greedy rebalancing, and a parallel-service scenario with an Erlang-C benchmark.

**Tools:** Python, NumPy, Matplotlib, and the standard-library `random`, `heapq`, and `math` modules.

Open `queueing_theory.ipynb` in Google Colab or Jupyter and run the cells in order. For a local environment, install the dependencies with `pip install numpy matplotlib`.

The notebook retains recorded simulation outputs. Results depend on model assumptions and finite simulation horizons; Erlang-C is an approximate benchmark.
